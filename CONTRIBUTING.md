# Contributing Guidelines

Thank you for your interest in contributing to this project! To keep everything organized and easy to maintain, please follow the steps below.

## Reporting Bugs or Suggesting Enhancements
* Before opening a new Issue, please check the **Issues** tab to ensure the bug or idea hasn't already been reported.
* When reporting a bug, clearly describe what happened, what you expected to happen, and include screenshots or error logs if possible.

## Submitting Code (Pull Requests)
1. **Fork** this repository to your own GitHub account.
2. Create a new branch for your changes (`git checkout -b feature/your-feature-name`).
3. Make your changes and test the code locally to ensure nothing is broken.
4. Commit your changes with a clear message (`git commit -m "Add new feature"`).
5. Push the branch to your Fork (`git push origin feature/your-feature-name`).
6. Open a **Pull Request** in this original repository explaining what was changed and why.

## General Rules
* Follow the existing code style and formatting conventions used in the project.
* Keep each Pull Request focused on solving a single issue or adding a single feature.
